# 麻雀教科書

麻雀をまったく知らない人が、短い解説とドリルで戦い方を身につけるインタラクティブ教科書（スマホ縦持ち向け）。
超初級から上級までの5レベル。問題はプロ雀士役の作問と、別のプロ雀士役のブラインド審査を通したものだけを公開しています。

- 公開ページ: https://yoyoyoyooo68.github.io/mahjong-textbook/
- 仕様: [設計図.md](設計図.md)
- 開発: `npm install` → `npm run check`（型検査・Lint・テスト）→ `npm run serve`（http://localhost:5181/）
